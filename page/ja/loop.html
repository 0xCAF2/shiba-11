繰り返し（ループ）

同じ処理を何度も繰り返す必要がある場面では、ループを使うと便利です。

プログラミングにおけるループは、いくつかの種類が用意されていることが多いですが、基本的には以下のように分けられます。

  • n 回だけ、繰り返す
  • 条件を満たす間、繰り返す
  • リストや配列から、要素を順番に取り出しながら、繰り返す

ループを使う時は、注意が必要

特に2番目の「条件を満たす間、繰り返す」では、条件を正しく設定しないと無限ループになる可能性があります。無限ループになると、プログラムを強制終了するしか方法がなくなってしまいます。

どんな場合にループを使う？

「n 回繰り返す」時には、ループの回数を直接数値で指定するだけでなく、変数を使って指定することもできます。

そうすると、はじめからループの回数が決まっていなくても、プログラムの実行時に変更可能になります。 例えば、次の例を見てください。これは文字列の中から特定の文字を探して、最初に見つかった位置を求めるプログラムです。 

      
        mojiretsu = "ドレミファソラシド"
        moji = "ド"

        i = 0
        ichi = -1
        nagasa = 文字の長さ(mojiretsu)
        nagasa 回繰り返す:
          もし mojiretsu[i] == moji:
            ichi = i
            ループを終了する
          i = i + 1
        表示する（ichi）

このプログラムでは文字が見つかったらその位置を表示し、見つからなければ -1 を表示します。

mojiretsu は任意の文字列で、内容を変えたとしても、その他の部分はそのまま使えます。 こちらのページで、プログラムを実際に動かして確認できます。

試してみる：

  • 最初は「ド」を探すようになっています。「ミ」を探すように変更します。（ここでは、リストの最初の要素は 0 番目と数えます。また、1文字ずつ区切られることに注意してください。）
  • 他の文字も探してみて、入っていない文字はどうなるか確認します。
  • 変数 mojiretsu の内容を自由に変えてみましょう。
