Distinguishing the Three "Gigas"

A commonly used unit for data size is GB (gigabyte, or giga). Depending on the context, the true meaning of giga can vary, so caution is needed.

The first is giga as the amount of data transmitted over a network. This is when we say we "consume" giga.

The second is giga as the amount of data stored on storage devices (HDDs, SSDs, etc.). This refers to the size of data recorded on disks that remain even when the power is off.

Finally, the size of computer memory, also known as main memory. When programming commands to "store" data, this memory is used.

For example, when storing the integer 7,

data = 7

The memory contains the integer data as 8 bytes (or 4 bytes).
