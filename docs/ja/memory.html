３つの「ギガ」を区別しよう

普段よく使うデータの大きさの単位として GB（ギガバイト、あるいはギガ）がありますね。場面によって、ギガの本当の意味は異なるので注意が必要です。

1つは、ネットワークで送受信したデータ容量としてのギガ。ギガを消費すると言った時です。

2つ目は、ストレージ（HDDやSSDなど）に保存されるデータ容量としてのギガ。こちらは電源を切っても保存されるようなディスク上に記録されるデータの大きさを指します。

最後に、主記憶といわれるコンピュータのメモリの大きさ。プログラミングで「記憶する」命令のときに使われるのは、このメモリです。

例えば、整数の 7 を記憶するとき、

data = 7

メモリには 8 バイト（あるいは 4 バイト）の整数型データとして存在します。
