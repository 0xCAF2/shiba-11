コンピュータは「記憶する」「計算する」のが得意

プログラミングでは、計算結果を記憶しておいて後から使うための命令があります。

「変数を使う」という言い方もします。変数というと数学の用語ですが、ここではシンプルに「データに名前をつける」ことだと考えてください。

例えば、買い物をするとき、あめ玉1個の値段が 50 円だとすると、プログラミング的には

candy = 50

のような書き方をします。そして 3 つ買ったとき、商品の合計を計算するためには

total = candy * 3

とします。

  2. 変数名を自分で考えて、変えてみましょう。結果はどうなりますか？

ポイント

  • データには、わかりやすい名前をつけることが重要です。
  • 計算結果を使うときは、変数名を使って参照します。
